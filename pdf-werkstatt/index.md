# PDF Werkstatt

Create and edit PDFs on your phone. No upload, no tracking, no ads.

PDF Werkstatt is an Android app (package `com.gdato.pdfwerkstatt`). Everything it does happens on the phone itself:
there is no server behind it, so your files have nowhere to go.

## What it does today

Make a PDF from:

- **Photos** you pick from the phone.
- **Scans** of paper documents, taken with the camera.
- **Text** you type or paste.
- **Web pages**, from the address you enter (Google Play edition).

Work on a PDF you already have:

- **Merge** several PDFs into one.
- **Split** a PDF or **remove pages** from it.
- **Compress** it to make the file smaller.
- **Password**: protect a PDF with a password.

## Free, all features included

The app is free, and every feature is there for everyone. There are no ads and no account. If it saved you time, you
can buy me a coffee; nobody has to.

## The promises

- **Your files never leave the phone.** The app has no server and uploads nothing.
- **No tracking.** No analytics, no advertising ID, no crash reporting.
- **No ads.**
- **No hidden processes.** The app works only while it is open.

The [privacy policy](privacy.md) says exactly what the Google Play edition does with Google Play, the document
scanner and web pages.
